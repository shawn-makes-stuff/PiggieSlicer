# PiggieSlicer V2 status — 2026-10-17
## Goal
PiggieSlicer is an "all printer" slicer like OrcaSlicer, built on PrusaSlicer 3.0.0-alpha12. It is rebranded (piggie pink #D07682 + piggie black #292929, sticker logo) and has no Prusa cloud. Its features copy Orca's real logic: Orca printer profiles, external multi-material units (AMS/ACE/CFS/MMU) on any tool, and an Orca-style left sidebar.
